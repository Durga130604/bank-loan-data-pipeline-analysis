# bank-loan-data-pipeline-analysis
End-to-end bank loan data analysis project using Excel, Pentaho ETL, SQL (40+ queries), Python (EDA), and Power BI dashboard for insights.

# Overview
This project focuses on analyzing bank loan data to extract meaningful insights and understand customer behavior, loan distribution, and risk patterns. It is an end-to-end data analytics project covering data cleaning, ETL, SQL analysis, Python-based EDA, and dashboard visualization.

# Tools & Technologies Used

* Excel – Data cleaning and preprocessing
* Pentaho (ETL) – Data extraction, transformation, and loading into SQL
* SQL – Data analysis using 40+ queries (basic to advanced)
* Python – Exploratory Data Analysis 
  * Pandas
  * NumPy
  * Matplotlib
  * Seaborn
* Power BI – Interactive dashboard and visualization

#  Project Workflow

1. Data Cleaning (Excel) -

   * Verified and cleaned dataset
   * Removed inconsistencies and handled missing values

2. ETL Process (Pentaho)

   * Extracted CSV data from Excel
   * Transformed and loaded data into SQL database

3. SQL Analysis -

   * Wrote 40+ queries using:

     * SELECT, WHERE, GROUP BY, HAVING
     * Joins, Aggregations
     * Window functions and advanced queries
   * Generated insights like loan distribution, customer segmentation, and risk patterns

4. Python (EDA) -

   * Performed exploratory data analysis
   * Identified trends and patterns
   * Created new features for better analysis
   * Visualized data using charts and graphs

5. Power BI Dashboard -

   * Built an interactive dashboard
   * Visualized key KPIs and insights
   * Enabled better decision-making through visuals


#  Key Insights -

* Identified patterns in loan active and default
* Analyzed customer segments based on loan behavior
* Observed trends in loan amount distribution
* Detected potential risk indicators
